## 作品について

仏教協会（代表者 木津無庵）が、釈尊の伝記を経とし経典を緯に編んだ聖典。八編に分けて、序歌から涅槃までを日本語に訳して収める。大正 14 年（1925 年）に新訳仏教聖典普及会から出た。国立国会図書館の目次の字のままの見出しが付く。巻頭の序・凡例・目次、巻末の索引と地図は入れていない。

国立国会図書館デジタルコレクションの「インターネット公開（保護期間満了）」の資料です。

## 本文の作り方

国立国会図書館デジタルコレクション（インターネット公開）の全文テキスト（OCR）をそのまま収めた。1 段落が底本の 1 コマ（見開き）。校正はしていないので、振り仮名や柱の混じり、読み違いが残る。
